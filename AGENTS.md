## Project notes (And/or Labs)

- **This site is the Mainline template, unmodified** (shadcnblocks/mainline-astro-template @ f92afce). Allowed edits: colour token values and font declarations in `src/styles/global.css` and `BaseHead.astro`; content (strings, links, image paths, data-array entries) in `src/components/blocks/*`, `src/consts.ts` and `src/content/`; image files in `public/`. Nothing else: no class, markup, token, spacing, radius or component changes, and no new components. If content does not fit a Mainline block, stop and ask.
- This rule overrides the global design, accessibility and personality rules. Flag conflicts; do not resolve them in code.
- Verify before every commit: `node ../andor-ds/scripts/check.mjs .` must print OK. `src/pages/*` is not covered; the only page change from upstream is Pricing removed from `index.astro`.
- Theme values live in `@andor/ds` (`themes/andor.css`): primary/ring `#1B4DFF`, Geist for display and text, Departure Mono for mono.
- Images replacing Mainline assets are generated by `.scratch/gen_assets.py` at the original dimensions.
- Claims rule: VJ led marketing and sales ops at Blockthrough and AdPushup through their acquisitions. Never "exited founder".
- Dev: `npm run dev` (Astro 5, as pinned by Mainline). Deploy: `npm run build && npx wrangler pages deploy dist --project-name andorlabs --branch <branch>` (Git auto-builds are disconnected).
