What is real, what is modeled.

Connectome. 1,045 cells and 17,224 directed connections from a MaleCNS v1.0 locomotor subgraph, extracted by DesktopFly. The neural display runs an uncalibrated leaky integrate-and-fire model over those measured connections. It is not a whole-brain simulation. Market inputs, neural-to-memory interpretation, and typing are engineered demonstration mappings.

Jev. Call Jev sends a real server-side API request. Until a real response or verified recording is available, no decision or trade is displayed. A recording retains the exact SDK request, response, measured call duration, and token usage. Jev returns a batch of typed answers; the display does not invent a token stream. Neural activity is computed locally, cached, and replayed at 0.2× model time for inspection.

Execution. Simulated budget starts at $4,000 / $3,500 / $2,500. A shift moves a policy-selected percentage of the source channel’s allocation. Total budget is conserved. No real spend, invented returns, or fabricated reward.
